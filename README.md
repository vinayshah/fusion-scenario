# Workfront Fusion Blueprints

A collection of Workfront Fusion scenario blueprints. Each folder contains a blueprint JSON, screenshots, and a README.

## Scenarios

| Folder | Description |
|--------|-------------|
| [company-billing-rates](./company-billing-rates/) | Syncs billing rates from Workfront Planning into Workfront's native billing rate system |

## How to Import a Blueprint

1. Open Workfront Fusion
2. Create a new scenario
3. Click `...` → **Import Blueprint**
4. Select the `.json` file from the relevant folder
5. Reconnect any connections — connection IDs in blueprints are environment-specific and will not transfer
